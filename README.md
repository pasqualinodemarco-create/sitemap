# Esporta sitemap Micologia BF

Plugin WordPress per esportare una sitemap XML delle pagine, degli articoli e delle schede di Archivio Micologico pubblicate. Esclude i contenuti protetti da password.

## Installazione e uso

Carica lo ZIP installabile da **Plugin → Aggiungi nuovo → Carica plugin** e attivalo. Come amministratore, vai in **Strumenti → Esporta sitemap** e premi **Scarica sitemap.xml**.

Il file viene scaricato sul computer. Per renderlo disponibile ai motori di ricerca va pubblicato sul sito e, se desiderato, inviato a Google Search Console.

Richiede WordPress 6.0 e PHP 7.4 o versioni successive.
